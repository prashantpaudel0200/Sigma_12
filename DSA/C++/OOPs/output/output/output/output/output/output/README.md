
# C++ Programming Concepts

A collection of C++ programs demonstrating
fundamental programming concepts and
Object-Oriented Programming (OOP).

## Concepts Covered

| No. | Concept | Description |
|---|---|---|
| 1 | Classes and Objects | Introduction to OOP |
| 2 | Inheritance | Code reusability |
| 3 | Function Overloading | Compile-time polymorphism |
| 4 | Pointers | Memory addresses and references |
| 5 | File Handling | Reading and writing files |

## Technologies Used
- C++
- GCC / Clang Compiler
- VS Code

## How to Run

Compile any program using:

```bash
g++ main.cpp -o main
```

Run:

```bash
./main
```

## Purpose

This repository is maintained for learning,
practicing, and documenting C++ programming
concepts.
