## 📈 Learning Philosophy

My approach is simple:

1. Learn the concept.
2. Write the code myself.
3. Test it and understand the output.
4. Debug errors instead of blindly copying solutions.
5. Apply the concept in a practical project.
6. Refactor and improve the code as my understanding grows.

I believe that understanding *why* code works is just as important as knowing *how* to write it.
